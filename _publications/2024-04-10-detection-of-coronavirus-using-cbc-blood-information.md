The abbreviation of PCR test is Polymerase Chain Reaction test which is done to detect genetic material from a specific organism like a virus. Since the outbreak of COVID-19, it has been a challenging task to detect the presence of coronavirus in the shortest possible time. However, RNA amplification techniques like PCR tests have made it possible to detect the coronavirus in laboratory environments through some experts. Still, people question whether they should get the test done because of how long it takes and how much it costs. By recognizing the potential problems of PCR tests, we addressed the solution by analyzing the CBC blood cells of the patients when they tested positive for coronavirus. In comparison with PCR tests, we have come up with an innovative approach in this article for COVID-19 detection using CBC blood cells, which can provide the coronavirus detection result as soon as possible. We’ve trained and tested a dataset of 4474 patients with both COVID-19 positive and negative cases using some machine learning models to analyze how the blood cell elements change for both cases. We also compared the models after analyzing the data to ensure which model can be used to detect the COVID-19 virus with better accuracy results.
