Nowadays, an intuitive user interface is very crucial to ensure user acceptance of any kind
of software solution. Thus, it is always required to test the intuitiveness as well as usability of a website
through an empirical study involving individuals or experts on how intuitive each of the elements of the
interface signs is. Recent studies mostly focused on experts and user-based evaluation, where very little
attention has been paid to evaluating the system with the help of artificial intelligence (AI). Therefore,
the objectives of this research are to identify the interactive systems automatically and effectively; and to
propose an AI-based solution for assessing the system’s intuitiveness for reducing its navigational error and
enhancing its usability. To attain these objectives, we have developed an AI agent that takes user input to
automatically navigate websites. It creates reports on navigation evaluations which can be compared with
manual navigation performed by human testers. According to the generated reports, it has been found that
the system performs 70.65% similarly to human users. This proposed agent can assist designers, developers,
and HCI experts in quickly evaluating and redesigning any type of software solution to make it simpler and
more efficient.
